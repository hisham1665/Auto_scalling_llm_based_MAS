# DRTAG

Dynamic Real-Time Agent Generation starts with seed agents and begins collaboration. After each response, the manager evaluates the bounded current context. If the structured generator returns a valid distinct role, the factory creates it and the registry makes it active. The new agent is then given a first participation turn before the manager may terminate, proving that generation is integration rather than display-only metadata.

DRTAG is bounded by `MAX_AGENTS`, `MAX_AGENT_GENERATIONS_PER_RUN`, and `MAX_TURNS`. A duplicate, malformed, or empty generated specification is logged and ignored while existing agents continue.
